# Yr7 Spanish Listening 2026

Self-marking listening quizzes for Year 7 Spanish. Each quiz has an embedded audio clip,
~20 questions in two blocks, and instant per-block feedback.

**Live site:** https://wanly20.github.io/Yr7_spanish_listening_2026/

All Spanish vocabulary is restricted to the class vocabulary list.

## Adding a quiz

1. Drop `NN_<slug>_quiz.html` and its `NN_<slug>.mp3` into the repo root.
2. Add a link row to `index.html`.
3. Commit and push — GitHub Pages redeploys automatically.
